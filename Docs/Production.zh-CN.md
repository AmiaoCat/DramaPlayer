# 短剧播放生产指南

[参数与调试参考](Configuration.zh-CN.md)覆盖会话默认值、各类小窗和模板参数、日志事件及排查步骤。

## 开源对标

| 参考项目 | 对 DramaPlayer 的启发 |
| --- | --- |
| [Player（约 2.2k stars）](https://github.com/piemonte/Player) | 播放状态、生命周期和播放质量数据都需要让宿主直接接入。DramaPlayer 按一次播放尝试提供首帧、卡顿与结束事件。 |
| [KSPlayer（约 1.7k stars）](https://github.com/kingslay/KSPlayer) | 多音轨和字幕是跨地区发行的基本能力。DramaPlayer 使用 AVFoundation 的原生媒体选项，沿用系统字幕与语言偏好。 |
| [CachingPlayerItem（约 550 stars）](https://github.com/neekeetab/CachingPlayerItem) | 渐进式 MP4 缓存与 HLS 分片缓存需要不同的实现。DramaPlayer 保留宿主缓存接口，Demo 用临时 MP4 验证预取、命中与播放器复用。 |
| [Mux Player Swift](https://github.com/muxinc/mux-player-swift) | 流媒体消费和播放体验监控可以一起接入。DramaPlayer 输出结构化事件，由宿主接到自己的监控系统。 |

## 推荐接入方式

- **剧集列表**：使用稳定、唯一的业务剧集 ID。先提交有序列表，再在页面可播放时激活会话。持续订阅状态，分别显示封面、缓冲、解锁和错误界面。
- **快滑和连播**：先使用 `.preparedPlayer`，用实际剧集验证从第 N 集滑到第 N+1 集时的首帧。流量敏感场景可以切换预加载策略；当前集的播放器和进度会保留。
- **流媒体**：使用支持多档位的 HLS 源。省流模式通过码率偏好影响 AVFoundation 的自适应选择。播放源的档位、编码格式、音轨和字幕发布由内容侧提供。 [Apple HLS 创作规范](https://developer.apple.com/streaming/hls-authoring-specification-for-apple-devices/)
- **鉴权**：预加载和播放都检查权限。签名 URL 由 resolver 提供并声明过期时间。账户切换或权限发生全局变更时刷新已缓存的授权和播放器。
- **埋点**：按冷启动、续播、预加载命中等场景分桶，统计首帧 P50/P95、启动失败率、卡顿次数和时长。区分用户退出、待解锁和播放失败。使用稳定剧集 ID，并由宿主提供网络类型、App 版本等上下文。

## 发布前验收

| 验收项 | 需要验证的路径 |
| --- | --- |
| 连续翻页和焦点 | 快速前后切、跨集跳转、末集完成、手动暂停后复入、后台回前台、音频中断。 |
| 内容和网络 | 在目标 iPhone 上使用实际 CDN 的 HLS/MP4，在 Wi-Fi、蜂窝及限速网络比较首帧、卡顿与失败率。 |
| 资源占用 | 连续播放和滑动几十集，记录内存峰值、预取流量和冷/热首帧差异。 |
| 权限与恢复 | 签名过期、剧集解锁、缓存文件损坏后回源、切账号后的资源隔离。 |
| 国际化内容 | 使用上线素材逐项检查配音、普通字幕、无障碍字幕以及切换后音画同步。 |
| 横竖版和折叠屏 | 用 iPhone Duo 检查外屏、内屏、半折叠、旋转和 Split View。播放到非首集时切换屏幕，检查同一剧集继续播放，标题、控件和返回入口留在安全区。 [Apple iPhone Duo 适配指南](https://developer.apple.com/iphone-duo/prepare/) |
| 封面与首帧 | 验证封面慢、404、无封面、首帧先到及快速切集。确认无旧图串集，封面失败不会阻止视频开始，封面迟到也不会重新挡住视频。 |
| 布局模板和小窗 | 用同一素材依次试 6 个比例的 Fit 和 Fill。小窗输入指定宽高、移动及缩放，再切换到较小窗口并返回。检查画面与封面一致、手柄未越过安全区，展开后时间和暂停状态保持。 |
| 超时与日志 | 让源请求超出预算再返回，确认迟到结果不会接管播放器。令缓存命中但无法就绪，确认仅回源一次。开启调试日志，验证首帧与失败可关联到会话和播放尝试，日志样本里无媒体地址或签名。 |

当前 SDK 提供 HLS 播放、宿主缓存扩展点和本地示例。正式发行还需要按业务部署的 CDN 和真机矩阵给出 QoE 基线。FairPlay、持久化离线 HLS、独立字幕文件和 CDN 故障切换是后续独立的能力项。
